## Featured Projects

### RaceLab

**Windows telemetry, session recording, and in-game overlay for F1 25 and Forza Horizon 6.**

RaceLab is a multi-game motorsport telemetry application built with Rust, Tauri, React, and TypeScript.

- Automatic F1 25 and Forza Horizon 6 detection
- Live telemetry with game-specific views
- Automatic session recording and persistence
- Mixed-game session history
- F1 lap, sector, event, tyre, fuel, ERS, and race-context data
- Click-through F1 overlay that keeps game focus
- Local-first storage with no account or cloud requirement
- Windows installer and tagged releases

[Repository](https://github.com/tahagurvardar/racelab) · [v2.0.0 Release](https://github.com/tahagurvardar/racelab/releases/tag/v2.0.0)

### CommitTrail

**Engineering portfolio platform built around verifiable project evidence.**

A full-stack system for turning repository activity into structured project stories while keeping evidence, privacy, and publishing boundaries explicit.

- GitHub App integration for tracked repositories
- PostgreSQL worker with retries, leases, idempotency, and dead-letter handling
- Versioned public profiles and project revisions
- Workspace-scoped authorization and privacy-safe publishing
- Next.js, PostgreSQL, Prisma, Better Auth, and background workers

[Repository](https://github.com/tahagurvardar/committrail) · [Public Demo](https://committrail.vercel.app)

### SeatFlow

**Multi-tenant event ticketing platform focused on transactional integrity.**

- Versioned venues and seat maps
- Atomic seat holds backed by PostgreSQL
- Simulated payment flow with verified webhooks
- QR tickets, refunds, disputes, and financial ledger
- Background reconciliation jobs and automated delivery pipeline

[Repository](https://github.com/tahagurvardar/seatflow) · [Live Demo](https://seatflow-staging.vercel.app)

### QueueForge

**Deterministic queue-scheduling simulation in the browser.**

- Seeded workloads and reproducible simulation results
- FIFO and shortest-estimated-processing-time scheduling
- Web Workers for simulation and comparison
- Browser-local persistence and deterministic replay
- Versioned JSON/CSV exports

[Repository](https://github.com/tahagurvardar/queueforge) · [Live Demo](https://queueforge-five.vercel.app)

### WordX

**Turkish and English word puzzle with multiple game modes.**

- Classic, Quick Rush, and Daily Challenge
- Guest gameplay and browser-facing product flow
- Optional account, history, and achievement system in the codebase
- Next.js, TypeScript, Prisma, PostgreSQL, and Playwright

[Repository](https://github.com/tahagurvardar/wordx) · [Staging Demo](https://wordx-staging.vercel.app)
